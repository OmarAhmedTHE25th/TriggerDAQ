  <Card title="Zero Hot-Path Allocations" icon="rocket">

  </Card>
  <Card title="Bit-Identical AVX2 L1 &amp; PI Prescaler" icon="setting">
    Compile-time AVX2 calorimeter and muon reduction kernels verified bit-identical to C++20 scalar across 50k frames, paired with an EMA-smoothed closed-loop PI prescaler locking <code>Critical</code> discovery rules at <code>1.0×</code>.
  </Card>
  <Card title="CERN Domain Fidelity" icon="star">
    3564-bunch LHC orbit/BCID filling scheme with abort-gap exclusion, validated Run Control FSM, per-second Luminosity Block ledgers, live DQM histograms, and sub-detector Event Builder fragment assembly.
  </Card>
  <Card title="GIL-Free nanobind &amp; Zero-Copy NumPy" icon="laptop">
    Python drives declarative trigger menus, runtime seqlock hot-reloads, a live Rich/ANSI telemetry dashboard, and zero-copy CRC32C-verified <code>.daq</code> inspection with import-time C++ layout checks.
  </Card>
